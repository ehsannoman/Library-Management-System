# 📚 BookOrbit — Library Management System

**Your Library’s Digital Sphere**

BookOrbit is a Java-based desktop Library Management System designed to simplify and streamline everyday library operations. Built with **Java Swing** and **Apache Derby Database**, it provides an intuitive interface for managing books, members, book circulation, and administrative records.

## ✨ Features

### 🔐 Admin Authentication
- Admin login and signup
- Secure access to the administrative dashboard
- Admin logout functionality

### 📊 Dashboard
- Overview of total books
- Total registered members
- Currently issued books
- Defaulter statistics

### 📖 Book Management
- Add new books
- Update existing book information
- Delete book records
- Manage the library's book collection

### 👥 Member Management
- Register new members
- Update member information
- Delete member records

### 🔄 Book Circulation
- Issue books to registered members
- Process book returns
- Maintain issued book records

### 📋 Records & Reports
- View complete library records
- Browse issued books
- Manage and view the defaulter list

## 🛠️ Technology Stack

| Technology | Purpose |
|---|---|
| Java | Core application development |
| Java Swing | Desktop graphical user interface |
| Apache Derby | Relational database management |
| JDBC | Database connectivity |

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Java Development Kit (JDK)
- Apache NetBeans IDE or another Java IDE
- Apache Derby Database

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ehsannoman/Library-Management-System.git
   ```

2. Open the project in your preferred Java IDE.

3. Configure the Apache Derby database connection.

4. Make sure the required database and dependencies are properly configured.

5. Build and run the application.

## 📁 Project Overview

BookOrbit is organized around the core operations of a library, providing a centralized desktop solution for administrators to manage library resources and member activities.
